# Checkpoints

Pretrained model weights are not redistributed. Download them from their official sources and place them as follows:

```text
checkpoints/
├── scgpt/
│   ├── args.json
│   ├── vocab.json
│   └── best_model.pt
└── Geneformer-V1-10M/
    └── ... official checkpoint files ...
```

The paper uses the scGPT whole-human checkpoint and Geneformer V1-10M.
